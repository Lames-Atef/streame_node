# File Reader Using Streams

## Description
This project demonstrates how to read a file using Readable Streams in Node.js.
The file is read in chunks and each chunk is logged to the console.

## How to Run
1. Make sure Node.js is installed
2. Add text inside big.txt
3. Run:
   node index.js

## Concepts Used
- Node.js Streams
- fs module
- data, end, error events
